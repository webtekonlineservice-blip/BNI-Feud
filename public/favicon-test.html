📱 Generate Apple Touch Icon (Optional)

To create the PNG version for iOS home screens:

  1. Visit CloudConvert or similar
  2. Upload /img/favicon.svg
  3. Set output size to 180x180 pixels
  4. Download and save as public/img/apple-icon.png

Note: The SVG favicon already works great for all modern browsers. The PNG version is only needed for iOS home screen icons and some older browsers.
